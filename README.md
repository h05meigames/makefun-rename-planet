Entry for the [Rename the Planet](https://make.fun/bounty/u-motasimfuad-rename-the-planet-094b0369) bounty on make.fun: one line, under 200 characters, giving a planet in our solar system a funny new name and saying why.

## Entry (116 characters)

> Earth is now 'The Group Project' — the only planet with 8 billion roommates and not one of them takes out the trash.

`main.ts` writes that line to `/output/entry.txt` and prints it with its character count when run with `node main.ts`.
